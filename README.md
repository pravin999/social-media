# social-media

Social media analysis tools and utilities.

## Projects

### 📊 [Ticker Sentiment Analysis](./ticker-sentiment/)

X (Twitter) sentiment analysis for any stock or crypto ticker. Get real-time sentiment reports, bullish/bearish breakdowns, and top posts for any ticker symbol.

**Quick start:**
```bash
cd ticker-sentiment
pip install -r requirements.txt
cp .env.example .env  # Add your X Bearer Token
python3 analyze TSLA
```

See the [ticker-sentiment README](./ticker-sentiment/README.md) for full documentation.
